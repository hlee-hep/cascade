# Cascade 0.3.0-rc1

This prerelease freezes Cascade's first public plugin and workflow contract for
release-candidate validation.

Highlights:

- public C++ plugin ABI 3 with complete build-fingerprint validation;
- verified and optionally signed C++ and Python plugin packages;
- unified lifecycle, transactional outputs, snapshot caching, and provenance;
- bounded completion-driven DAG scheduling and subprocess isolation;
- typed controller-scoped runtime policy and the public Python `Controller` API;
- DAG, input-hashing, and output-hashing benchmark baselines;
- ASan/UBSan, installed-runtime, plugin, and toy-analysis CI coverage.

The attached benchmark JSON files are a reference measurement from the release
runner. They are diagnostic baselines, not performance compatibility guarantees.

This is a prerelease. API, ABI, or schema changes discovered during RC validation
will be documented before the final 0.3.0 release.
